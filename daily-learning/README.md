# Daily AI Product Learning

这里记录每天 15 分钟的 AI 产品练习。目标不是制造空提交，而是持续积累可以被复用、讨论和验证的产品判断。

## 每日记录格式

新建 `YYYY-MM-DD-topic.md`，回答四个问题：

1. 我观察到了什么？
2. 有什么证据或案例？
3. 我的判断是什么？
4. 下一步准备验证什么？

## 每周主题

| 星期 | 主题 |
| --- | --- |
| 周一 | 竞品拆解 |
| 周二 | 模型评测 |
| 周三 | RAG / Prompt |
| 周四 | PRD / 用户体验 |
| 周五 | 数据与增长 |
| 周六 | 作品集打磨 |
| 周日 | 周复盘 |

真正有价值的连续贡献，应当让后来的人能从记录中获得方法、模板、数据或案例。
